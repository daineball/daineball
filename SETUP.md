# Install your GitHub profile

1. Sign into GitHub as `daineball` (or replace `daineball` throughout the files if your intended username is different).
2. Create a **public** repository whose name exactly matches your GitHub username (`daineball`). Initialize it with a README only if you intend to replace that README.
3. Copy the `README.md`, `assets/`, `scripts/`, and `.github/workflows/` contents from this package into the repository root.
4. Commit and push. The GitHub profile README will appear on your profile.
5. Under **Actions**, run **Refresh profile dashboard** once with `workflow_dispatch`. The workflow also runs daily.
6. If Actions cannot push, set **Settings → Actions → General → Workflow permissions** to **Read and write permissions**, subject to your repo/org policy. No personal access token is required.

## Notes
- The dashboard is an SVG generated by Python's standard library. GitHub profile READMEs cannot execute arbitrary JavaScript.
- Public repository and follower counts come from the GitHub API. If the API is unavailable, the renderer shows `—` instead of inventing numbers.
- No private tokens, workstation IP addresses, SSH details, or secrets are embedded.
- The dashboard shows project capabilities, not live workstation uptime or live GPU utilization.
- Edit `README.md` and `scripts/generate_profile.py` to change wording or branding.
